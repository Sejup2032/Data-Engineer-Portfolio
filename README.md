### 🏦 1. Regulatory Reporting Automation Platform on Azure
*An enterprise-grade banking compliance platform automating Basel III Capital Adequacy and AML/FINTRAC reporting with audit-ready historical tracking.*

* **Tech Stack**:  ![Azure Data Factory](https://img.shields.io/badge/Azure_Data_Factory-0078D4?style=flat-square&logo=microsoft-azure&logoColor=white)
![Azure Databricks](https://img.shields.io/badge/Azure_Databricks-FF3621?style=flat-square&logo=databricks&logoColor=white)
![PySpark](https://img.shields.io/badge/PySpark-E25A1C?style=flat-square&logo=apache-spark&logoColor=white)
![Delta Lake](https://img.shields.io/badge/Delta_Lake-0A0A0A?style=flat-square&logo=delta&logoColor=white)
![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=flat-square&logo=powerbi&logoColor=black)
![Logic Apps](https://img.shields.io/badge/Logic_Apps-0078D4?style=flat-square&logo=microsoft-azure&logoColor=white)
![Terraform](https://img.shields.io/badge/Terraform-844FBA?style=flat-square&logo=terraform&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat-square&logo=github-actions&logoColor=white)

* **The Problem**: Manual regulatory reporting processes made Basel III Capital Adequacy Ratio (CAR) and AML/FINTRAC compliance reporting time-consuming, error-prone, and difficult to audit across multiple banking data sources.

* **Approach**:
  - Engineered a **Metadata-Driven Ingestion Framework** in Azure Data Factory using a Watermark-based CDC pattern to incrementally ingest transaction, mortgage, customer, and foreign exchange data from CSV files, REST APIs, and relational databases.
  - Built a scalable **Medallion Architecture (Bronze → Silver → Gold)** using ADLS Gen2, Azure Databricks, PySpark, and Delta Lake.
  - Developed a reusable **Data Quality Framework** for schema validation, standardization, deduplication, exception handling, and quarantine processing of invalid records.
  - Implemented **SCD Type 2** processing using Delta Lake `MERGE INTO` operations to preserve complete historical customer and account changes.
  - Built a rule-based **AML Detection Engine** to identify suspicious transactions, unusual activity patterns, and high-risk transfers across millions of records.
  - Automated **Basel III Capital Adequacy Ratio (CAR)** calculations using risk-weighted asset models and capital exposure datasets.
  - Designed enterprise-grade **Star Schema** models and Power BI dashboards with **Row-Level Security (RLS)** for compliance monitoring and investigations.
  - Integrated **Azure Key Vault**, **Azure Monitor**, and **Logic Apps** for secure credential management, proactive alerting, and automated compliance report distribution.
  - Leveraged **Terraform** and **GitHub Actions** for Infrastructure as Code (IaC) and CI/CD deployment automation.

* **Results**:
  - Reduced manual regulatory reporting effort by **60%** through end-to-end automation.
  - Enabled audit-ready historical tracking and automated AML monitoring across millions of banking transactions.
  - Improved data quality, governance, and regulatory compliance readiness.
  - Eliminated manual report preparation and distribution through fully automated reporting workflows.

* **Code**: [View Repository](https://github.com/Sejup2032/Regulatory-reporting-automation-Basel-III-AML-FINTRAC-)

*An enterprise-grade platform handling streaming data with historical auditing.*

* **Tech Stack**: 
![Azure Databricks](https://img.shields.io/badge/Azure_Databricks-FF3621?style=flat-square&logo=databricks&logoColor=white) 
![DLT](https://img.shields.io/badge/DLT-FF3621?style=flat-square&logo=databricks&logoColor=white)

![PySpark](https://img.shields.io/badge/PySpark-E25A1C?style=flat-square&logo=apache-spark&logoColor=white) 
![ADLS Gen2](https://img.shields.io/badge/ADLS_Gen2-0078D4?style=flat-square&logo=microsoft-azure&logoColor=white) 
![Jinja2](https://img.shields.io/badge/Jinja2-B41717?style=flat-square&logo=jinja&logoColor=white)
![Unity Catalog](https://img.shields.io/badge/Unity_Catalog-FF3621?style=flat-square&logo=databricks&logoColor=white)
![Logic Apps](https://img.shields.io/badge/-Logic_Apps-0078D4?style=flat-square&logo=microsoft-azure&logoColor=white)

* **The Problem**: Schema drift and loss of historical user status during subscription changes.
* **Approach**:
  - Engineered a **Metadata-Driven Ingestion** layer in ADF using a Watermark pattern to handle incremental data loads across multiple tables via `ForEach` loops.
  - Implemented **Delta Live Tables (DLT)** for a declarative Medallion Architecture (Bronze → Silver → Gold).
  - Developed **SCD Type 2** logic for historical tracking and automated quality checks using **DLT Expectations**. Used **DABs** for CI/CD deployment.
  - Integrated **Azure Logic Apps** for automated pipeline failure notifications.

* **Results**:
  - Reduced ingestion compute costs by **45%** by moving from full-load to incremental-load logic.
  - Automated the entire lifecycle from source-extraction to BI-ready Gold tables with zero manual intervention.

* **Code**: [View Repository](https://github.com/Sejup2032/Incremental-ETL-and-Dimensional-Modeling-Platform-on-Azure-Lakehouse-Architecture)
